# 🌦️ Weather

> A weather application built with Jetpack Compose, created as part of a ComposeChef challenge focused on building a weather app that remains resilient when network errors occur.

**Weather** is a small Android project designed to explore how to build a modern and reliable weather application while handling one of the most common problems in mobile development: **unreliable network connectivity**.

The main goal of the project is not simply to fetch and display weather data, but to understand how an application should behave when the network is slow, unavailable, or fails unexpectedly.

### 🎯 Project Goals

Through this project, I explore:

* 🌤️ Fetching and displaying weather information
* 🌐 Handling network requests and failures
* ⚠️ Managing different error states
* 🔄 Handling loading, success and error states
* 📱 Building the UI with Jetpack Compose
* 🧠 Managing UI state in a clean and predictable way
* 🛡️ Making the application resilient to network problems
* ✨ Providing a better user experience when something goes wrong

### 🧩 ComposeChef Challenge

This project was created as part of the **ComposeChef — "Créer une application météo résiliente aux erreurs réseau"** challenge.

👉 **Challenge:** https://composechef.com/fr/challenges/creer-une-application-meteo-resiliente-aux-erreurs-reseau?v2

The challenge provided the starting problem. The implementation is an opportunity to experiment, learn, and make architectural and technical decisions along the way.

> **The goal isn't just to make the app work when everything goes right — it's to understand what happens when it doesn't.**
